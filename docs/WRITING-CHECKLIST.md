# Writing checklist

Before committing a conceptual or explanatory document, ask:

- What is the actual claim?
- Which example carries the argument?
- Which common interpretation must not replace it?
- Did I explain the idea before introducing notation?
- Did I keep events separate from their representations?
- Did I keep state separate from meaning?
- Did observer time become object time?
- Did I introduce an unstated ontology, history or external viewpoint?
- Did I confuse missing evidence (`U`) with semantic invalidity (`C`)?
- Did I make self-reference automatically `C`?
- Did I turn a local profile into universal Onto4 semantics?
- Is the Russian prose natural and free of unnecessary English?
- Can a new reader understand the document without repository history?
